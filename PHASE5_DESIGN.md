
# PHASE 5 – Final Report and Demonstration

## 1. Objective

To prepare the final project report, demonstrate the working application and document the implementation of all algorithms.

## 2. Project Implementation

The Mini Courier Planner integrates the following algorithms:

- Merge Sort for parcel prioritization
- 0/1 Knapsack using Dynamic Programming
- Dijkstra's Algorithm for shortest paths
- Nearest Neighbor for delivery route approximation

## 3. Final Application Output

The application successfully displays:

- Prioritized parcel list
- Selected parcels
- Total loaded weight
- Total parcel value
- Distance matrix
- Final delivery route
- Algorithm execution times
